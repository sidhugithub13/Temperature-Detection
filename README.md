# Temperature-Detection

The objective is to measure the humidity and moisture value of the environment using DHT11 sensor and Raspberry pi.

**DHT 11 sensor:**
The DHT11 is a low-cost temperature and humidity sensor. It isn’t the fastest sensor around but it's cheap price makes it useful for experimenting for projects 
where you don’t require new readings multiple times a second. The device only requires three connections to the Pi.
